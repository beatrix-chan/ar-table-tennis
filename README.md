## Quick Start

> [!NOTE]
> **Prerequisite**:
> - [Python](https://www.python.org/)
> - [Miniconda](https://www.anaconda.com/docs/getting-started/miniconda/system-requirements) (add to PATH variable if you want to run `conda` in your usual terminal)
> - [Git](https://git-scm.com)

1. Clone repository
    ```sh
    git clone https://https://github.com/<username>/ar-table-tennis.git
    ```
    > [!TIP]
    > Replace `<username>` with yours if you have forked this repository. Otherwise, replace it with my username (`beatrix-chan`).
2. Enter the repo's directory
    ```sh
    cd ar-table-tennis
    ```
3. *(Optional)* Create a virtual environment
    ```sh
    conda update --all
    ```
    ```sh
    conda config --add channels conda-forge
    conda config --set channel_priority strict
    ```
    ```
    conda create -n ar-tt python=3.14
    conda activate ar-tt
    ```
4. Install dependencies
    ```sh
    pip install -r requirements.txt
    ```
5. Launch the app
    ```sh
    ```

And a GUI should pop up, enjoy!
